# @sqlew/full

Scoped alias of the full [sqlew](https://www.npmjs.com/package/sqlew) package (all RDB drivers: SQLite, PostgreSQL, MySQL).

```bash
npm install -g @sqlew/full
# equivalent to:
npm install -g sqlew
```

For Cursor Cloud / ephemeral VMs with remote Postgres, prefer [`@sqlew/pg`](https://www.npmjs.com/package/@sqlew/pg) instead.

Semver is kept in lockstep with `sqlew`. Publish with `npm publish --access public`.
